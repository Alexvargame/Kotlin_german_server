# 🇩🇪 Deutsche

Мобильное приложение для изучения немецкого языка с упражнениями, системой прогресса и поддержкой пользователей.

---

## 📌 Описание

**Deutsche** — это приложение для изучения немецкого языка через интерактивные упражнения.
Пользователь может тренировать грамматику, отслеживать прогресс и получать помощь через встроенный чат поддержки.

## 🌐 Сервер (Django)

Серверная часть проекта реализована на Django и использует SQLite3.

⚠️ **Важно:** на данный момент сервер может не запускаться корректно после скачивания.

### Установка (планируемая)

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Сервер доступен в репозитории, но требует дополнительной настройки.

---

## 🏗️ Архитектура сообщений (чат)

Каждое сообщение содержит:

* `server_id` — id на сервере (null до синхронизации)
* `sync_status`:

    * `PENDING` — создано локально
    * `SENT` — отправлено
    * `ERROR` — ошибка

### Алгоритм:

1. Создание локального сообщения (`PENDING`)
2. Отправка на сервер
3. Успех → `SENT` + `server_id`
4. Ошибка → `ERROR`
